# 📘 Aula 2: Produto x Projeto – Qual a diferença?

## 🎯 Objetivos da aula

- Diferenciar os conceitos de produto e projeto.
- Entender por que startups desenvolvem produtos e executam projetos.
- Identificar exemplos de produtos e projetos no mercado.
- Compreender a relação entre ambos.

# 📦 O que é um produto?

Um **produto** é algo criado para gerar valor continuamente para seus usuários.

Ele pode ser:

- um aplicativo;
- um sistema;
- um site;
- um serviço.

Após ser lançado, ele continua existindo e recebendo melhorias.

Exemplos:

- aplicativo bancário;
- plataforma de estudos;
- rede social;
- sistema de vendas.

# 📋 O que é um projeto?

Um **projeto** é um conjunto de atividades com:

- início;
- planejamento;
- execução;
- término.

Seu objetivo é entregar um resultado específico.

Depois que esse resultado é entregue, o projeto termina.

## 📌 Exemplo

Imagine que uma empresa deseja criar um aplicativo.

O **projeto** é todo o trabalho necessário para construir esse aplicativo.

Quando o aplicativo é lançado, ele se torna o **produto**.

Ou seja:

```
Projeto
      ↓
Entrega
      ↓
Produto
      ↓
Melhorias contínuas
```

## ⚖️ Diferenças principais

| Projeto | Produto |
| --- | --- |
| Possui início e fim | Evolui continuamente |
| Tem objetivo específico | Gera valor ao usuário |
| Entrega um resultado | Continua sendo melhorado |
| É temporário | É permanente enquanto existir demanda |

## 🚀 Como isso funciona em startups?

Em startups, é comum existir:

- vários projetos acontecendo ao mesmo tempo;
- um único produto sendo desenvolvido continuamente.

Exemplo:

Produto:

> Aplicativo de organização financeira.
> 

Projetos:

- criar nova tela de login;
- adicionar notificações;
- melhorar o sistema de busca.

Cada projeto melhora o mesmo produto.

## 👨‍💻 Onde o programador participa?

O desenvolvedor participa dos projetos, mas sempre pensando no produto.

Durante seu trabalho, ele precisa refletir:

- essa funcionalidade melhora a experiência do usuário?
- ela resolve um problema real?
- agrega valor ao produto?

Essa visão é importante para que o desenvolvimento esteja alinhado aos objetivos da empresa.

## 📌 Exemplo prático

Imagine um aplicativo de transporte.

Produto:

- o aplicativo utilizado pelos clientes.

Projetos:

- implementar pagamento por PIX;
- adicionar avaliação dos motoristas;
- melhorar o mapa.

Cada projeto contribui para melhorar o mesmo produto.

Fim da aula!
